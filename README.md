# PrintFlow — Print & Packaging Operations

Multi-supplier print and packaging order management, production tracking, quality control, and delivery logistics management.

## Features

- **Dashboard**: Real-time overview of active orders, production throughput, and supplier metrics.
- **Orders**: Complete tracking from artwork approval through final delivery.
- **Production Tracking**: Early bottleneck detection and pipeline management.
- **Supplier Management**: Relationship, capacity, and SLA tracking.
- **Purchase Orders**: Order-linked purchase order workflows.
- **Delivery & Logistics**: Real-time dispatch and tracking with logistics partners.
- **Quality Control**: Inspection checklists, defect logs, and sign-offs.
- **Reports & Analytics**: Executive reporting across suppliers and production lines.

## Development

You need Node.js (v20+ recommended) and npm / bun.

```sh
npm install
npm run dev
```

## Tech Stack

- TanStack Start & TanStack Router
- React 19
- Tailwind CSS v4
- TypeScript
- Lucide React
